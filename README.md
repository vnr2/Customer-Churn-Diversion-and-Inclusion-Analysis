# Customer-Churn-Diversion-and-Inclusion-Analysis

This Project is conducted by PwC Switzerland Job Simulation aka Virtual Internship. It consists of three case studies on different datasets.

Case Study - 1 (Call Center Trends Analysis)
![image](https://github.com/user-attachments/assets/638d3a11-b113-49fd-b3e6-684ee1f8342e)

This case study deals with call center trends where we analyze the number of incoming calls, call agent's performance, Speed of answer, call duration trends on a daily and hourly basis, and customer satisfaction ratings. The dashboard defines key KPIs that impact customer satisfaction as well as the performance of the call agents. The goal is to identify the opportunity where the performance can be monitored and enhanced.

Tasks

* Create a dashboard in Power BI for Claire that reflects all relevant Key Performance Indicators (KPIs) and metrics in the dataset. Get creative!
* What do customers want? Our client is a big telecom company that needs to know.
* Possible KPIs include Overall Customer Satisfaction, Overall Call Answer Abandoned, Calls by Time Average, Speed of Answer Agent's Performance, Average Handle Time vs Call Answered
